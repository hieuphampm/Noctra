NOCTRA STUDIO `v0.1.1-pre` introduces **Internet Mode** (disabled by default to preserve NOCTRA's privacy-first posture) so users can perform authorized domain port scanning and HTTP/HTTPS security audits directly inside NOCTRA STUDIO with full human-in-the-loop approval and local audit logging.
