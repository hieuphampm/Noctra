NOCTRA STUDIO `v0.1.3-pre` introduces **Browser Automation (`/browser`)**, allowing AI to navigate URLs, analyze live UI components, click buttons and links, enter text, fill forms, scroll pages, search page content, and extract structured data directly within persistent per-conversation browser sessions with strict sensitive-action confirmation guardrails.
