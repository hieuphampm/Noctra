## Multi-Provider Management

NOCTRA AI lets you configure any number of independent AI providers—such as cloud OpenAI-compatible endpoints, OpenRouter-style gateways, or local LAN servers running Ollama or LM Studio.

## Steps to Add a Provider

1. Open the navigation drawer or **Settings → Providers**.
2. Tap **Add Provider**.
3. Enter a display label, base URL (e.g. `https://api.openai.com/v1`), and optional API key.
4. Tap **Test Connection** to verify endpoint reachability and list available models.
5. Save the provider and optionally mark it as your active default.

## Switching Providers

You can switch active providers directly from the chat composer or conversation settings without losing prior message history.
