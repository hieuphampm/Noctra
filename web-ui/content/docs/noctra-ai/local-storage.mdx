## On-Device Hive Vault

NOCTRA AI persists all user content locally on the Android device using Hive:

- Conversations and message threads
- System prompts and custom AI personas
- Reusable prompt templates
- Application appearance and transmission preferences

## Exporting & Secret Redaction

You can export conversations as JSON or Markdown from the **Privacy Vault**. The export service automatically scrubs secrets so API keys are never included in exported files.

## Auto-Deletion & Full Wipe

From the Privacy Vault, you can configure local retention policies or execute a full local data wipe that clears stored conversations and credentials from the device.
