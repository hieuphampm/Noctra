## Secret-Free Exports

Both NOCTRA AI and NOCTRA STUDIO support exporting user data without leaking credentials:

- **NOCTRA AI**: Exports conversations in **JSON** or **Markdown** formats from the Privacy Vault while automatically stripping or redacting secrets.
- **NOCTRA STUDIO**: Supports portable secret-free workspace backup export/import via its Rust storage layer, excluding OS keyring credentials.

## Full Local Wipe

Both applications provide a destructive local wipe option to clear stored conversations, preferences, and local databases directly from your device.
