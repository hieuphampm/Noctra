## What Is a Skill?

Skills in NOCTRA STUDIO follow the `SKILL.md` format (YAML frontmatter + Markdown instructions) and can include supporting reference files.

## Installation Sources

- **Built-in Skill Editor**: Create and organize Skills with supporting files directly inside NOCTRA STUDIO.
- **Local Folder or ZIP Import**: Import self-contained Skill packages from disk.
- **Marketplace Adapters**: Browse curated catalogs (Official MCP Registry, GitHub directories, custom JSON catalogs).

## Safety Policy

External Skills are marked **unverified** by default. Supporting `scripts/` directories are indexed as metadata only and are **never executed automatically**.
