## No Account Required

When you open NOCTRA AI or NOCTRA STUDIO for the first time, there is no sign-up screen, cloud sync prompt, or telemetry opt-out dialog. Both apps initialize local storage immediately on your device.

## First Steps Checklist

1. **Choose an AI Provider**: Decide whether to connect a local inference server (such as Ollama or LM Studio on your network) or a cloud OpenAI-compatible API endpoint.
2. **Add Provider Credentials**: Open the Provider Manager and enter your Base URL, optional API key, and model identifier.
3. **Test Connectivity**: Use the built-in connection check (`GET /models` or test chat ping) before saving.
4. **Verify Privacy Preferences**:
   - In **NOCTRA AI**, optionally enable the Biometric Lock Gate and review attachment/history transmission toggles.
   - In **NOCTRA STUDIO**, review default tool permission policies (`Ask every time` is recommended for external MCP tools).
